# Exemplars

One file per shipped PR worth copying from. Shipped code is not automatically correct, so
every exemplar has a **Known flaws** section; an exemplar without one is incomplete.

File name: `pr-<number>-<slug>.md`.

```markdown
# PR <number>: <title>

**What it shows:** the one decision or pattern worth copying, in a sentence.
**Copy this:** the file paths and the specific choice (an API shape, a test, a story).
**Known flaws:** what the PR got wrong or left undone, so nobody copies that part.
**Source:** the PR link and the review comments that settled the choice.
```
